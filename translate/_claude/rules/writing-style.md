# 문체 규칙

모든 보고서 내용에 적용한다: 초안 원문, 모든 수정본, 작업 파일, 최종 결과물.

## 언어
- 제목, 표 머리글, 항목명, 상태값을 포함해 모든 보고서 내용을 한국어로 쓴다 (`CLAUDE.md`의 언어 정책 참고).
- 영어는 `CLAUDE.md`의 "보고서 내용에서 허용되는 영어"에 해당할 때만 쓴다: 고유명사, 제품명, 용어집 약어, 원어 출처 제목, 그리고 출처 표시와 출처 섹션 안의 URL·파일 이름.
- 제목이나 본문에 보고서 ID, 슬러그(예: `ev-market-growth`), 폴더 이름(예: `inputs/`)을 넣지 않는다. 한국어 주제를 쓰고, 폴더 이름 대신 `내부 자료` 또는 `웹 자료`라고 쓴다.
- 영어로 된 원본 내용은 자연스러운 한국어로 옮긴다. 보고서에 영어 문장을 남기지 않는다.
- `docs/template-headings.md`에 정해진 한국어 제목을 쓴다.

## 문장
- 기본은 개조식 종결로 쓴다: `~함`, `~임`, `~됨`.
- 사용자가 서술형을 명시적으로 요청할 때만 `~습니다`체를 쓴다.
- 한 문장은 한글 60자 이내로 쓴다.
- 결론을 먼저 쓰고 근거를 뒤에 쓴다 (두괄식).

## 숫자와 날짜
- 천 단위 쉼표를 쓴다: `1,234,567`.
- 금액: `억 원` / `만 원` 단위를 쓴다. 예: `12억 3,400만 원`.
- 비율: 소수점 첫째 자리까지. 예: `12.3%`.
- 증감: 부호를 붙이고 절대값과 증감률을 함께 쓴다. 예: `+1,200건(+8.5%)`.
- 날짜: `2026. 11. 7.(토)`. 기간: `2026. 11. 2.~11. 8.`

## 용어
- 약어는 처음 나올 때 풀어 쓴다. 예: `KPI(핵심성과지표)`.
- 권장 용어는 `docs/glossary.md`를 따른다.
- 한 보고서 안에서는 한 개념에 한 용어만 쓴다.
