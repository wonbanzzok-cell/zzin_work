# 웹 조사 규칙

보고서 자료를 웹에서 가져올 때마다 적용한다.

## 웹을 쓰는 경우
- `inputs/`가 기본 자료다. 웹은 `inputs/`에 보고서와 관련된 자료가 없거나 사용자가 웹 조사를 요청할 때만 쓴다.
- 웹 조사는 `web-researcher` 에이전트가 맡는다. `researcher` 에이전트는 웹 검색을 하지 않는다.
- researcher가 `관련 자료 없음`으로 보고하면 사용자에게 묻지 않고 바로 `web-researcher`를 실행한다.
- 웹 자료를 `inputs/`에 저장하지 않는다.

## 출처 우선순위
1. 정부·통계 기관, 국제기구 (예: IEA, OECD)
2. 기업 IR 자료와 공식 보도자료
3. 공신력 있는 조사 기관과 업계 단체
4. 주요 언론사

블로그, 커뮤니티, SNS, 출처 없는 모음 페이지, AI 생성 요약은 피한다. 낮은 순위의 출처는 더 높은 순위의 출처가 해당 사실을 다루지 않을 때만 쓰고, 그 사실을 `raw_web.md`에 적는다.

## 사실 수집
- 한국어와 영어로 여러 검색어를 써서 검색한다.
- 사실은 `WebFetch`로 연 페이지에서만 가져온다. 검색 결과 요약문에서만 본 수치는 절대 쓰지 않는다.
- 가장 최근 자료를 우선한다. 모든 수치의 기준 기간을 기록한다. 예: `2025년 연간`.
- 실적과 전망을 구분한다. 전망에는 출처와 목표 연도를 표시한다. 예: `2030년 전망`.
- 가능하면 핵심 수치를 독립된 다른 출처 하나로 교차 확인한다. 출처끼리 다르면 두 값을 각각의 출처와 함께 남기거나 `[확인 필요: 출처 간 수치 불일치]`로 표시한다.
- 한국어가 아닌 내용은 한국어로 번역한다 (`CLAUDE.md`의 언어 정책 참고).
- 발표된 값은 그대로 쓴다. 새 값을 계산하지 않는다. 계산한 값은 `data-handling.md`의 계산 규칙을 따른다.

## 출처 표기
형식: `[출처: <publisher>, "<title>", <URL>, <published date>]`

예: `[출처: 국제에너지기구(IEA), "Global EV Outlook 2026", https://www.iea.org/..., 2026. 5.]`

- 게시일을 알 수 없으면 `게시일 미상`이라고 쓴다.
- 초안에서는 출처 섹션에 전체 출처가 있을 때 `raw_web.md`의 출처 번호로 줄여 쓸 수 있다. 예: `[출처: S1]`.

## 출처 기록 (`raw_web.md`)
사용한 모든 출처를 한국어로 아래 형식에 맞춰 기록한다.

```
# 웹 자료 원문: <report-id>
접속일: 2026. 11. 7.(토) | 검색어: <queries>

## S1. <publisher> — <title>
- URL: <URL>
- 게시일: 2026. 5. | 신뢰 등급: 1
- 발췌:
  - <fact, translated into Korean> (기준 기간: 2025년 연간)

## 제외한 출처
- <URL>: <reason>
```

- 출처 번호는 S1, S2, ... 순으로 매기고 절대 바꾸지 않는다. 그래야 노트와 초안에서 참조할 수 있다.
- 신뢰 등급은 위 출처 우선순위의 번호(1~4)다.
