# 데이터 처리 규칙

## 원본 보호
- `inputs/`의 파일은 절대 수정하지 않는다. 읽기 전용으로 다룬다.
- 수치나 사실을 지어내지 않는다. 정보가 없으면 보고서에 `[확인 필요: <한국어 사유>]`를 적는다.

## 출처 표기
- 보고서의 모든 수치에 출처 파일을 표기한다. 예: `[출처: sales_2026-10.xlsx]`.
- 문서를 인용할 때는 파일과 섹션 또는 페이지를 표기한다. 예: `[출처: 회의록_1105.docx, 2쪽]`.
- 한국어가 아닌 자료를 인용할 때는 한국어로 번역하고 출처는 그대로 남긴다.

## 웹 자료
- 웹 자료는 `inputs/`에 관련 자료가 없거나 사용자가 웹 조사를 요청할 때만 쓴다. 웹 자료는 `web-researcher` 에이전트가 `.claude/rules/web-research.md`에 따라 수집한다.
- 웹에서 가져온 사실은 발행 기관, 제목, URL, 게시일로 출처를 단다. 예: `[출처: 국제에너지기구(IEA), "Global EV Outlook 2026", https://www.iea.org/..., 2026. 5.]`.
- 사실은 `WebFetch`로 실제로 연 페이지에서만 가져온다. 검색 결과 요약문에서 가져오지 않는다.
- 모든 웹 수치에 기준 기간을 밝힌다. 예: `2025년 연간 판매량`.
- 모든 웹 출처를 접속일과 함께 `workspace/<report-id>/raw_web.md`에 기록한다.
- 출처끼리 다르면 두 값을 각각의 출처와 함께 보여 주거나 `[확인 필요: 출처 간 수치 불일치]`로 표시한다.
- 발표된 값은 그대로 쓴다. 계산한 값이 필요하면 스크립트로 계산해 `calc.md`에 기록하고, 그렇지 않으면 `[확인 필요]`로 표시한다.

## 계산
- 계산해서 얻은 값은 계산식과 함께 `workspace/<report-id>/calc.md`에 한국어로 기록한다.
  예: `달성률 = 실적 1,230 / 목표 1,500 × 100 = 82.0%`
- 합계와 비율은 스크립트 결과(`data-summary` 스킬)를 쓴다. 머릿속으로 계산하지 않는다.

## 개인정보
- 보고서에 개인정보를 넣지 않는다: 개인 이름(보고서 작성자 제외), 전화번호, 이메일, 주민등록번호.
- 고객이나 직원은 직책이나 익명 ID로 표기한다.
