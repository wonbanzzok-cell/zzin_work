# 용어집

보고서 내용에 쓰는 권장 용어. 항상 "권장" 열의 용어를 쓴다.

## 용어
| 권장 | 지양 | 의미 |
|---|---|---|
| 매출 | 매상, 판매액 | 매출액 |
| 달성률 | 달성도, 달성율 | 달성률 (실적 / 목표 × 100) |
| 전월 대비 | 전달 대비 | 전월 대비 증감 |
| 전년 동기 대비 | 작년 대비 | 전년 같은 기간 대비 증감 |
| 고객사 | 거래처, 클라이언트 | 고객 회사 |
| 완료 | 끝남, 종료됨 | 완료됨 |

## 약어
보고서마다 처음 나올 때 풀어 쓴다.

| 약어 | 첫 표기 |

| MoM | MoM(전월 대비) |
| YoY | YoY(전년 동기 대비) |
