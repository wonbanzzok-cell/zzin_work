# Writing Style Rules

Applies to all report content: the original draft, every revision, working files, and deliverables.

## Language
- Write all report content in Korean, including headings, table headers, labels, and status values (see the Language Policy in `CLAUDE.md`).
- Use English only as allowed by "Allowed English in report content" in `CLAUDE.md`: proper nouns, product names, glossary abbreviations, original source titles, and URLs or file names inside source tags and the sources section.
- Never put report IDs, slugs (e.g., `ev-market-growth`), or folder names (e.g., `inputs/`) in titles or body text. Use the Korean topic, and write `내부 자료` or `웹 자료` instead of folder names.
- Translate English source content into natural Korean. Do not leave English sentences in a report.
- Use the fixed Korean headings in `docs/template-headings.md`.

## Sentence Style
- Use the Korean bullet-point ending (개조식) by default: `~함`, `~임`, `~됨`.
- Use the formal `~습니다` style only when the user explicitly asks for prose.
- Keep each sentence under 60 Korean characters.
- Lead with the conclusion, then give the evidence (두괄식).

## Numbers and Dates
- Use thousands separators: `1,234,567`.
- Money: use `억 원` / `만 원` units, e.g., `12억 3,400만 원`.
- Percentages: one decimal place, e.g., `12.3%`.
- Changes: show the sign and both absolute and relative values, e.g., `+1,200건(+8.5%)`.
- Dates: `2026. 11. 7.(토)`. Periods: `2026. 11. 2.~11. 8.`

## Terms
- Spell out an abbreviation on first use, e.g., `KPI(핵심성과지표)`.
- Follow `docs/glossary.md` for preferred terms.
- Use one term per concept within a report.
